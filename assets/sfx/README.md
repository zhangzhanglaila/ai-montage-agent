# 音效素材目录

`packages/sound_engine` 会优先使用本目录下的音效文件（`<kind>.wav`）。

## 支持的类型

| 文件名 | 用途 | 触发时机 |
|--------|------|----------|
| `impact.wav` | 低频撞击 | 强拍 |
| `whoosh.wav` | 呼啸过渡 | 剪辑点 |
| `riser.wav` | 上升铺垫 | 高潮前 |
| `click.wav` | 轻微点击 | 弱拍点缀 |

## 说明

- 本目录默认**为空**：缺失的音效由 ffmpeg 程序化合成（见 `sfx_library.py`），
  零外部依赖、零版权风险、可离线运行。
- 如需更好的听感，可放入自有素材（建议 44.1kHz / 单声道或立体声 WAV）。
- **请勿放入来源不明的音乐或音效**，避免版权问题。
