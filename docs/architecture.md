## 模块详解

### 1. 视频理解模块 (video-understanding)

负责视频的智能分析和理解。

#### 核心功能

- **镜头检测 (ShotDetector)**
  - 使用PySceneDetect进行场景分割
  - 支持多种检测算法
  - 输出镜头时间点和片段

- **特征提取 (FeatureExtractor)**
  - 提取关键帧
  - CLIP embedding
  - 动作识别

- **语义分析 (SemanticAnalyzer)**
  - 人脸检测和情绪识别
  - 场景分类
  - 物体检测

- **高光评分 (HighlightScorer)**
  - 动作强度评分
  - 人脸情绪评分
  - 镜头运动评分
  - 综合高光分数

### 2. 节拍引擎模块 (beat-engine)

负责BGM分析和节拍同步。

#### 核心功能

- **节拍检测 (BeatDetector)**
  - 使用librosa进行节拍检测
  - BPM估算
  - 强拍/弱拍识别

- **能量分析 (EnergyAnalyzer)**
  - 计算能量曲线
  - 高潮部分检测
  - 动态能量变化

- **结构分析 (StructureAnalyzer)**
  - 音乐结构识别
  - 段落分类
  - 情绪变化检测

- **卡点同步 (BeatSyncEngine)**
  - 镜头与节拍对齐
  - 速度拉伸
  - 动作对齐

### 3. 时间轴引擎模块 (timeline-engine)

负责整体编排和规划。

#### 核心功能

- **情绪曲线 (EmotionCurve)**
  - 生成情绪变化曲线
  - 支持多种风格
  - 平滑插值

- **节奏规划 (RhythmPlanner)**
  - 生成节奏曲线
  - 与节拍同步
  - 剪辑点生成

- **时间轴规划 (TimelinePlanner)**
  - 情绪弧线规划
  - 节奏曲线规划
  - 镜头多样性保证
  - 智能镜头分配

### 4. 蒙太奇引擎模块 (montage-engine)

负责转场效果和视频合成。

#### 核心功能

- **转场引擎 (TransitionEngine)**
  - 多种转场效果
  - 智能转场推荐
  - FFmpeg滤镜实现

- **视频合成 (VideoComposer)**
  - 镜头拼接
  - 转场应用
  - BGM添加
  - 特效应用

### 5. 渲染引擎模块 (render-engine)

负责最终视频生成。

#### 核心功能

- **FFmpeg执行器 (FFmpegExecutor)**
  - 视频裁剪
  - 视频拼接
  - 速度调整
  - 音频添加
  - 最终导出

- **视频渲染器 (VideoRenderer)**
  - 渲染配置管理
  - 批量处理
  - 进度追踪

## 技术栈

### 核心依赖

| 类别 | 技术 | 用途 |
|------|------|------|
| 视频处理 | FFmpeg | 视频剪辑、合成、转码 |
| 镜头检测 | PySceneDetect | 场景变化检测 |
| 音频分析 | librosa | 节拍检测、音频特征提取 |
| AI/ML | PyTorch | 深度学习框架 |
| 视觉理解 | CLIP | 视觉-语言对齐 |
| 后端框架 | FastAPI | API服务 |
| 任务队列 | Celery | 异步任务处理 |
| 数据库 | PostgreSQL | 数据存储 |
| 缓存 | Redis | 缓存和消息队列 |

### 可选依赖

| 类别 | 技术 | 用途 |
|------|------|------|
| 动作识别 | InternVideo2 | 视频动作识别 |
| 语音识别 | Whisper | 语音转文字 |
| 前端框架 | Next.js | Web界面 |
| UI组件 | shadcn/ui | 界面组件库 |

## 扩展性设计

### 插件化架构

各模块采用插件化设计，易于扩展：

- 镜头检测算法可替换
- 转场效果可自定义
- 评分维度可配置
- 情绪曲线可定制

### 配置驱动

核心行为通过配置驱动：

- 风格参数配置
- 评分权重配置
- 转场效果配置
- 输出格式配置
